# 🎮 Mini Game Projects Collection

Bu repo, HTML, CSS ve JavaScript kullanılarak geliştirilmiş **3 farklı mini oyunu** içerir.
Her proje, farklı bir oyun mekaniği ve frontend becerisi geliştirmek için hazırlanmıştır.

---

## 🧩 Projeler

### 🧱 Breakout Game

Klasik tuğla kırma oyunu.

* Canvas tabanlı oynanış
* Seviye sistemi
* Can ve skor takibi
* Mobil uyumlu kontrol

---

### 🎴 Memory Card Game

Hafıza ve dikkat geliştirme oyunu.

* Kart eşleştirme mekaniği
* 3 zorluk seviyesi
* Süre ve hamle sayacı
* Emoji tabanlı tasarım

---

### 🏓 Pong Game

Retro Pong oyununun modern versiyonu.

* Basit AI rakip
* Klavye ve touch kontrol
* Skor sistemi
* Akıcı canvas animasyonu

---

## ⚙️ Kullanılan Teknolojiler

* HTML5
* CSS3
* Vanilla JavaScript
* Canvas API

---

## 🎯 Amaç

Bu proje seti:

* Oyun geliştirme mantığını öğrenmek
* DOM ve canvas kullanımını geliştirmek
* Kullanıcı etkileşimini yönetmek
  için hazırlanmıştır.
